# Neon Rift Survivor V3.3 — Rift Classes & Boss Overhaul

V3.3 is a gameplay expansion built on top of the stable V3/V3.1/V3.2 systems. It keeps the existing Canvas engine, rarity cards, EVO progression, custom difficulty, and performance caps while adding more meaningful run identity and enemy behavior.

## Rift Classes

Players select one class before entering the rift. The selected class is stored locally.

| Class | Role | Starting bonus |
|---|---|---|
| Assault | Damage / Critical | +18% damage, +8% critical chance |
| Vanguard | Armor / Survival | +35 max HP, +12% armor, +0.4 HP/sec regeneration |
| Velocity | Speed / Cooldown | +18% movement speed, 10% faster cooldowns and Pulse fire, +10% pickup range |

Classes change starting stats without replacing the existing upgrade system, so every class can still build any weapon/EVO combination.

## Enemy archetypes

V3.3 adds behavior differences instead of only changing enemy HP or movement speed.

- **Charger** — approaches slowly, shows a visible warning ring, then performs a high-speed charge.
- **Shooter** — tries to maintain range, strafes, and fires hostile projectiles at the player.
- **Splitter** — breaks into two fast shards when defeated.
- **Shielded** — has increased durability and begins regenerating after avoiding damage for a short period.
- **Chaser** — keeps the original direct pursuit behavior so the arena still has a readable baseline enemy.

More advanced archetypes are introduced later in a run so the opening remains understandable for new players.

## Rift Warden boss

Bosses now use a three-phase system based on remaining HP.

### Phase I — Control
- Orbit-style movement around the player.
- Six-way radial projectile bursts.
- Dedicated boss health/phase HUD.

### Phase II — Pressure
- Three-shot aimed spreads.
- Telegraph before a high-speed dash.
- More aggressive movement.

### Phase III — Enrage
- Faster pursuit.
- Ten-way radial projectile bursts.
- Additional aimed projectile pressure.
- Stronger visual phase color.

Impossible mode can still create double bosses, and the boss HUD reports when multiple Rift Wardens are active.

## Build synergies

Synergies are separate from EVOs. An EVO improves one weapon after meeting its Level 5 + passive requirement; a synergy rewards owning two compatible build pieces.

| Synergy | Requirement | Effect |
|---|---|---|
| Overload Grid | Arc Conductor + Plasma Pool | Enemies inside Plasma zones take additional Arc-based damage |
| Phase Fortress | Phase Field + Orbit Guard | Restores 18% of incoming damage, effectively reducing pressure |
| Precision Core | Prism Lance + Critical Module | Raises critical-hit damage |

Unlocked synergies appear in a small HUD and trigger an unlock banner.

## Run scoring

The V3.3 game-over screen calculates a final score from kills, time survived, bosses defeated, and EVOs, then applies a difficulty multiplier.

| Mode | Score multiplier |
|---|---:|
| Easy | ×0.80 |
| Standard | ×1.00 |
| Nightmare | ×1.50 |
| Impossible | ×2.25 |
| Custom | ×1.00 |

The summary also shows class, mode, survival time, kills, boss count, EVO count, and active synergies. The latest five runs are saved locally per difficulty.

## Architecture

V3.3 is implemented as `src/v3.3.js`, loaded after the stable V3 engine and V3.2 upgrade layer. The layer wraps selected engine functions such as reset, enemy spawning, update, drawing, and loadout updates. This lets the expansion add new behavior while keeping the existing engine easier to compare, test, or roll back.

The V3.3 stylesheet is isolated in `v3.3.css` and handles class cards, boss health UI, synergy indicators, and the run summary.

## Validation checklist

Before merging V3.3 to `main`:

- `src/v3.3.js` passes `node --check`.
- Start screen shows all three class choices.
- Each class changes the documented starting stats.
- Charger warning/charge works.
- Shooter can fire hostile projectiles.
- Splitter creates two shards on death.
- Shielded enemy can regenerate after avoiding damage.
- Boss health HUD appears at the boss wave.
- Rift Warden transitions through Phase I, II, and III.
- V3.2 rarity cards and rerolls still work.
- At least one synergy can unlock during a test build.
- Game-over summary renders and restart works.
- Mobile class layout remains readable.
