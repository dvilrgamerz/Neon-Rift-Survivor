# Neon Rift Survivor V4 — Rift Expedition

V4 is the first major progression-focused release. It keeps the V3 combat engine, V3.2 rarity/EVO layer, and V3.3 class/boss layer, then adds a modular V4 feature stack on top.

## Major systems

### Operators
V4 adds five Operators that combine with the existing Rift Class choice:
- Nova — precision and critical damage
- Titan — HP, armor, and shield
- Volt — starts with Arc Conductor and faster skills
- Ghost — movement and dodge
- Forge — starts with Rift Mine and larger area

### Arenas
- Neon City — energy surges / Grid Tyrant
- Void Factory — laser sweeps / Assembler Prime
- Frozen Rift — cryo slow zones / Cryo Colossus
- Magma Core — damaging magma vents / Inferno Engine
- Final Rift — anomaly hazards / Rift Sovereign

Arena selection changes hazards, boss presentation, and score multiplier.

### Run modes
- Endless — classic high-score survival
- Expedition — survive 6 minutes and defeat 2 bosses
- Daily Challenge — daily seeded run with locked Operator/Arena and its own leaderboard
- Rift Ascension — every boss increases enemy HP/speed/spawn/boss power and score potential

### Permanent progression
Runs earn Rift Cores. The capped Core Grid can improve starting damage, HP, movement speed, rarity luck, extra rerolls, shield, lifesteal, and dodge.

### Combat additions
- Shield absorption + regeneration
- Dodge
- Lifesteal based on actual damage dealt
- Burn, Shock, and Slow status behavior tied to existing weapons
- Elite enemy modifiers: Swift, Fortified, Explosive, Berserk, Vampiric
- Arena-specific boss attacks layered over the V3.3 Rift Warden phases

### Rarity
V3.2 base rarity rolls stay intact. V4 adds a separate **Mythic promotion** chance starting at 0.50%; Rift Luck increases that promotion chance. Mythic cards gain an additional +8% damage, +8 max HP and 8 HP heal.

### Boss rewards
Defeated bosses pause the run for a three-choice Rift Cache reward. Expedition/Daily completion can end the run with a victory result.

### Ultimate Synergies
- Supernova Grid — Arc + Plasma + Energy Cube
- Kinetic Tempest — Rift Disc + Kinetic Orb + Vector Boots
- Fortress Prime — Phase Field + Orbit Guard + Phase Armor
- Nova Barrage — Void Missile + Rift Mine + Reactor Fuel

### VFX + SFX
V4 generates original effects in-browser with Canvas and WebAudio. Existing abilities get distinct rings/sparks and generated sound cues. EVO, Synergy, Mythic, Legendary, boss, chest, damage and UI events have additional cues. No copied external game audio/assets are required.

### Leaderboards and stats
V4 stores Top-10 scoreboards locally by run mode + arena + difficulty, with a separate date-keyed Daily Challenge board. Entries include score, Operator, Class, time and bosses. Lifetime stats, achievements and up to 30 recent runs are stored in the versioned V4 save.

This leaderboard is intentionally offline/local in V4.0 so the game keeps $0 infrastructure requirements. The save model is structured so a future optional global backend can be added without removing local boards.

### Settings / accessibility
- SFX volume
- procedural ambient volume
- VFX intensity
- reduced motion
- damage/status text
- screen shake
- controller toggle
- fixed mobile joystick option
- performance mode

### Save system
V4 uses a versioned `neonRiftV4Save` object. The Settings panel can export/import the V4 save as encoded text. Leaderboards can be cleared independently.

### Controller
Left stick moves. A selects the first upgrade while the level-up screen is open; B can activate a normal reroll. Start pauses/resumes.

### PWA/offline
`manifest.webmanifest` + `sw.js` cache the static game files. The game can be installed by supported browsers and can load offline after the cache has been populated once.

## Architecture

V4 is split into small layers:
- `src/v4/config.js` — data definitions, save format, content config
- `src/v4/audio-vfx.js` — WebAudio cues + Canvas VFX wrappers
- `src/v4/gameplay.js` — Operators, progression effects, arenas, hazards, bosses, run scoring
- `src/v4/meta.js` — Expedition Hub, Core Grid, leaderboards, stats, settings, save tools
- `src/v4/rarity-patch.js` — Mythic promotion + progression rerolls
- `v4.css` — V4 UI and Mythic presentation
